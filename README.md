# QueueBot

Telegram-бот для электронной очереди студентов по учебным предметам.

Пользователь регистрируется, выбирает учебную группу, просматривает очереди по предметам и может занять место без лишней суеты.

## Возможности

- Регистрация пользователя после команды `/start`.
- Выбор и последующая смена учебной группы.
- Главное меню с доступными предметами.
- Просмотр очереди своей группы.
- Отображение никнеймов и Telegram username участников.
- Постановка в очередь.
- Защита от повторной активной записи.
- Завершение участия кнопкой `✅ Я всё`.
- Автоматическое обновление позиций.
- Административное управление группами и предметами.
- Хранение администраторов в базе данных.
- Логирование действий и ошибок.

## Технологии

- Python 3.11+
- python-telegram-bot
- PostgreSQL
- asyncpg
- Pydantic
- Docker Compose

## Установка

Клонируйте проект и перейдите в его каталог:

```bash
git clone <repository-url>
cd QeueBotNew
```

Создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Для Windows:

```powershell
.venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Настройка окружения

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=your_telegram_bot_token

DB_HOST=127.0.0.1
DB_PORT=5432
DB_NAME=queuebot
DB_USER=postgres
DB_PASSWORD=your_password

LOG_LEVEL=INFO
```

Токен Telegram-бота можно получить у [@BotFather](https://t.me/BotFather).

Доступные уровни логирования:

- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `CRITICAL`

## Запуск базы данных

Запустите PostgreSQL через Docker Compose:

```bash
docker compose up -d
```

При первом запуске автоматически создаются таблицы:

- `groups` — учебные группы;
- `courses` — предметы;
- `user` — пользователи;
- `list_queue` — записи очереди.

## Запуск бота

Из корня проекта выполните:

```bash
python -m bot.app
```

## Регистрация пользователя

После команды `/start` бот проверяет пользователя в базе данных.

Если пользователь новый:

1. Бот запрашивает имя.
2. Показывает доступные учебные группы.
3. Пользователь выбирает группу.
4. Регистрация сохраняется в базе данных.
5. Открывается главное меню.

Если пользователь уже зарегистрирован, бот сразу показывает приветствие и главное меню.

## Главное меню

В главном меню отображаются inline-кнопки с доступными предметами.

После выбора предмета пользователь видит:

- текущую очередь своей группы;
- никнеймы участников;
- Telegram username участников;
- собственную позицию;
- кнопку `➕ Встать в очередь`;
- кнопку `✅ Я всё`, если он уже стоит в очереди;
- кнопку `⬅️ Назад`.

После нажатия `✅ Я всё` запись закрывается, пользователь исчезает из активной очереди, а позиции остальных участников обновляются.

## Пользовательские команды

```text
/start — запустить бота или открыть главное меню
/help — показать справку
/change_group — сменить учебную группу
/cancel — отменить регистрацию или смену группы
```

## Административные команды

```text
/add_group <название> — создать группу
/groups — показать список групп
/edit_group <ID> <новое название> — переименовать группу
/delete_group <ID> — удалить группу

/add_subject <название> — создать предмет
/subjects — показать список предметов
/edit_subject <ID> <новое название> — переименовать предмет
/delete_subject <ID> — удалить предмет
```

Административные команды доступны только пользователям с `is_admin = TRUE`.

## Назначение первого администратора

Сначала пользователь должен зарегистрироваться через `/start`.

После этого откройте PostgreSQL:

```bash
docker compose exec queueDB psql -U postgres -d queuebot
```

Назначьте администратора по его Telegram ID:

```sql
UPDATE "user"
SET is_admin = TRUE
WHERE tg_id = 123456789;
```

Проверить результат:

```sql
SELECT id, tg_id, nicname, username, is_admin
FROM "user";
```

Чтобы забрать права администратора:

```sql
UPDATE "user"
SET is_admin = FALSE
WHERE tg_id = 123456789;
```

## Остановка

Остановить контейнер базы данных:

```bash
docker compose down
```

Остановить базу и удалить её данные:

```bash
docker compose down -v
```

Команда с флагом `-v` безвозвратно удаляет Docker volume с данными PostgreSQL.
